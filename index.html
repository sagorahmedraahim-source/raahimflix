CloudStream compatibility

CloudStream plugins are not directly executable in a browser PWA.

Adapter planned for a later step

CloudStream repositories often provide plugin code intended for the CloudStream runtime. This client can only integrate sources through a compatible, documented HTTP API or an adapter you control. It will not execute arbitrary plugin code in your browser.
